# 학습체크 (study-check)

아이들의 자기주도 학습 계획을 **주 단위(월~일)로 체크**하는 대시보드 웹 앱입니다.
위쪽에 요일, 왼쪽에 과목과 학습 내용이 있고, 칸을 누르면 그날 그 학습을 했다고 체크합니다.
아이가 여러 명이면 위쪽에서 아이를 골라 아이별로 따로 관리합니다.

학원노트(`10_Apps/academy-note/`)와는 별개의 앱이지만, 같은 디자인(남색 테마, 카드, 메뉴 배치)과 같은 기술 구성을 씁니다.

- 계획서: [docs/plan.md](docs/plan.md)
- 개발 중 정한 것들: [docs/decisions.md](docs/decisions.md)
- GitHub 저장소: https://github.com/LeePillWoo/study-check (`main` 브랜치, 공개)
- **데모 (GitHub Pages)**: https://leepillwoo.github.io/study-check/ — 삼성 인터넷 등 휴대폰 브라우저에서 바로 열 수 있습니다. `main`에 올리면 자동으로 다시 배포됩니다. (`.github/workflows/deploy-pages.yml`) 데이터는 그 브라우저 안에만 저장됩니다.

## 화면

| 메뉴 | 내용 |
|---|---|
| 홈 | 고른 아이의 주간 체크 보드. 제목 오른쪽에서 **계획표 / 요일별 / 체크표**를 고르고 **인쇄**합니다. 과목 이름을 누르면 과목 설정으로, 아래 "과목 추가"로 새 과목 |
| 과목 | 고른 아이의 과목 목록. 순서 바꾸기, 추가 |
| 설정 | 아이 관리. 인쇄와 백업은 준비 중 |

## 실행 방법

처음 한 번만 라이브러리를 설치합니다.

```
npm install
```

| 명령 | 용도 |
|---|---|
| `npm run dev` | PC에서 개발 서버를 켭니다. 브라우저에서 `http://localhost:5180` 을 엽니다. (학원노트는 5173) |
| `npm run dev:phone` | 폰에서도 접속할 수 있게 개발 서버를 켭니다. 폰을 PC와 같은 와이파이에 연결하고, 화면에 나오는 `Network:` 주소를 엽니다. |
| `npm run build` | 배포용 파일을 `dist/` 폴더에 만듭니다. |
| `npm run preview` | 만든 배포용 파일을 미리 봅니다. |
| `npm test` | 계산 테스트. 주 계산, 진행 세기 같은 계산이 맞는지 확인합니다. |
| `npm run test:e2e` | 화면 테스트. PC의 Edge로 휴대폰 세로·가로, PC 크기에서 기능을 자동으로 눌러 확인합니다. |

- 학원노트 개발 서버와 동시에 켤 수 있습니다. 포트가 다릅니다: 개발 서버 5180, 미리보기 5181, 화면 테스트 5198. (학원노트는 5173, 5199)
- `npm run dev:phone`을 처음 실행하면 Windows 방화벽 창이 뜰 수 있습니다. **개인 네트워크**만 허용합니다.

## 폴더 구조

```
study-check/
├─ docs/            계획서, 정한 것들
├─ design/          아이콘 원본(icon-source.png)과 잘라낸 아이콘(icon-cropped.png, 672×672 투명 배경)
├─ scripts/         crop-icon.py: 원본 그림에서 아이콘을 잘라 public/의 PNG들을 만듦 (python -I scripts/crop-icon.py design/icon-source.png)
├─ public/          아이콘 PNG(32, 64, 192, 512, apple-touch-icon) 같은 정적 파일
├─ src/
│  ├─ data/         저장소 계층과 데이터 기능 (아이, 과목, 학습 내용, 체크)
│  ├─ components/   여러 화면에서 쓰는 부품 (주간 보드, 체크 칸, 요일 고르기, 색 고르기)
│  ├─ layout/       화면 뼈대 (메뉴, 위쪽 막대, 아이 선택)
│  ├─ pages/        화면 (홈, 과목, 과목 설정, 설정, 아이)
│  ├─ hooks/, utils/  작은 도우미 기능 (날짜, 주 계산)
│  ├─ App.tsx       화면 주소 연결
│  ├─ main.tsx      시작 파일
│  └─ index.css     색상, 반응형 배치, 보드 스타일
├─ tests/e2e/       화면 테스트
├─ index.html
└─ package.json
```
