# 개발 중 정한 것들 (확인 부탁)

사용자 요청("주 단위 체크, 위쪽 월~일, 왼쪽 과목 설정, 아이별 분류, 학원노트 디자인")을 만들면서 세부를 정한 내용입니다. (2026-10-30)
바꾸고 싶은 항목이 있으면 말씀해 주세요. 대부분 쉽게 바꿀 수 있습니다.

## 화면과 사용 방식

| 번호 | 정한 것 | 이유 | 바꾸기 |
|---|---|---|---|
| 1 | **보드는 늘 아이 한 명 것만** 보여줍니다. 위쪽에서 아이를 고르고, 아이가 1명이면 선택이 숨고 화면 설명에 이름이 나옵니다. 학원노트에 있는 '전체' 보기는 없습니다. | 과목과 체크가 아이마다 다르고, 7칸 표를 아이별로 겹쳐 보여주기 어려워서 | 보통 (PC에서 아이들 보드를 나란히 보는 '전체'를 추가할 수 있음) |
| 2 | **과목 설정은 보드 왼쪽 과목 이름을 눌러** 엽니다. 보드 아래에 "과목 추가" 단추가 있고, 메뉴 "과목"에서도 목록과 순서 바꾸기를 할 수 있습니다. | 요청("좌측으로 과목 설정") | - |
| 3 | 과목 아래에 **학습 내용을 여러 줄** 둡니다. (예: 수학 → 문제집 2쪽, 연산 10분) 체크 칸은 학습 내용 줄마다 7개입니다. | 한 칸에 여러 내용을 넣으면 휴대폰에서 너무 좁아서 | - |
| 4 | 학습 내용마다 **계획 요일**이 있고 기본은 **평일(월~금)**입니다. 계획하지 않은 요일은 옅은 점으로 보이지만 **눌러서 체크할 수는 있습니다.** | 계획과 실제를 구분해서 보려고. 안 한 날은 비워두고 더 한 날은 체크 | 쉬움 (기본을 '매일'로 바꾸거나, 계획 없는 요일은 못 누르게) |
| 5 | **계획한 날이 지났는데 체크가 없으면 옅은 분홍**으로 보입니다. (놓친 날) 오늘은 아직 아닙니다. | 한 주 동안 못 지킨 날을 한눈에 보려고 | 쉬움 (끄기 가능) |
| 6 | 주는 **월요일에 시작**합니다. 보드의 왼쪽이 월, 오른쪽이 일입니다. | 요청("상단엔 월~일") | - |
| 7 | 진행 수 세기: **계획 = 계획한 요일 칸 수, 완료 = 체크한 칸 수** (계획 없는 날에 한 것도 셈). 비율은 100%를 넘지 않습니다. | 더 한 것도 보이게 | 쉬움 |
| 8 | 보드 위 **이번 주 진행**(완료/계획, 막대), 과목 띠 오른쪽에 **과목별 진행**, 아래 줄에 **요일별 완료 수**를 둡니다. | 어느 과목, 어느 요일이 약한지 보려고 | 쉬움 |
| 9 | 이번 주가 아닌 주를 보고 있으면 "이번 주로" 단추가, 이번 주면 "이번 주" 표시가 나옵니다. 주를 옮겨 **지난주 칸도 체크·취소**할 수 있습니다. | 빠뜨린 체크를 나중에 넣을 수 있게 | - |
| 10 | 휴대폰에서 왼쪽 열은 5.5rem이고 학습 내용 이름은 **두 줄까지** 보이고 넘치면 자릅니다. 넓은 화면은 열을 넓힙니다. 요일 줄은 스크롤해도 위에 붙어 따라옵니다. | 7칸이 화면 너비에 들어오게 (가로 스크롤 없음) | - |
| 11 | 과목 화면에서 **이름이 빈 학습 내용 줄은 저장하지 않습니다.** 학습 내용을 지우면 그 체크 기록도 지워집니다. (저장 전 안내 글) | 빈 줄 때문에 저장이 막히지 않게 | 쉬움 |
