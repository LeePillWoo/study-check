# 학습체크 계획서

- 작성일: 2026-10-30
- 상태: 1단계 완료, 인쇄 방식은 사용자와 논의 예정

## 1. 목표

아이들이 **자기주도 학습 계획을 지켰는지 주 단위로 체크**하는 대시보드입니다.

- 투두 리스트처럼 쓰되, 하루가 아니라 **한 주(월~일)**를 한 화면에 봅니다.
- **위쪽은 월~일 요일**, **왼쪽은 과목과 그 과목의 학습 내용**입니다. 과목은 직접 적습니다.
- 학습 내용마다 요일 칸이 있고, 칸을 누르면 그날 했다고 체크합니다.
- **아이별로 분류**합니다. 아이마다 과목과 체크 기록을 따로 둡니다.
- 학원노트와 **같은 디자인**을 씁니다. (남색 테마, 카드, 메뉴 위치)
- 서버 없이 기기에 저장합니다. (학원노트와 같은 방식)

## 2. 주요 기능

### ① 아이 관리

- 아이를 추가, 수정, 삭제하고 순서를 바꿉니다. 이름과 표시 색상을 정합니다.
- 아이가 2명 이상이면 화면 위쪽에서 아이를 고릅니다. 보드, 과목 목록이 그 아이 것으로 바뀝니다.

### ② 과목 설정 (아이별)

| 항목 | 예시 |
|---|---|
| 과목 이름, 표시 색상 | 수학 / 남색 |
| 학습 내용 (여러 개, 순서 있음) | 문제집 2쪽, 연산 10분 |
| 학습 내용마다 계획 요일 | 문제집 2쪽: 월~금, 연산 10분: 매일 |

- 보드 왼쪽의 과목 이름을 누르면 바로 과목 설정 화면이 열립니다. 보드 아래 "과목 추가"로 새 과목을 만듭니다.
- 메뉴 "과목"에서도 목록을 보고 순서를 바꿀 수 있습니다.

### ③ 주간 체크 보드 (홈)

- `‹ 10월 26일 ~ 11월 1일 ›` 로 주를 옮깁니다. 이번 주가 아니면 "이번 주로" 단추가 나옵니다.
- 요일 줄은 월~일이고 오늘은 남색 동그라미, 오늘 열은 옅은 남색 바탕입니다. 일요일은 빨강, 토요일은 파랑입니다.
- 과목마다 과목 색의 띠가 있고, 그 아래 학습 내용이 한 줄씩 있습니다.
- 칸 상태
  - 계획한 요일: 과목 색 테두리의 빈 네모 → 체크하면 과목 색으로 채워짐
  - 계획하지 않은 요일: 옅은 점 (눌러서 체크할 수는 있음)
  - 계획했는데 지난 날에 체크가 없음: 옅은 분홍 (놓친 날)
- 진행 표시: 위에 이번 주 완료/계획 수와 막대, 과목 띠 오른쪽에 과목별 진행, 아래 줄에 요일별 완료 수
- 보기 방식 (제목 오른쪽 단추, 마지막 선택 기억)
  - **체크표** (기본): 학습 내용이 한 줄씩, 줄마다 월~일 체크 칸 7개
  - **계획표**: 종이 주간 계획표처럼 왼쪽에 과목, 위에 요일, 칸 안에 그날 할 학습 내용. 학습 내용을 누르면 체크. 좁은 화면은 표 안에서 옆으로 밀어서 봄

### ④ 인쇄 (나중에)

사용자와 다시 이야기한 뒤 정합니다. 후보:

- 빈 체크표를 뽑아 아이가 손으로 체크하기
- 앱에서 체크한 결과가 든 주간표 뽑기
- 아이별로 한 장씩

지금은 브라우저 인쇄에서 메뉴와 단추만 숨기는 기본 스타일만 있습니다.

## 3. 저장 구조

학원노트와 같은 방식입니다. 모든 종류를 한 저장 공간(IndexedDB)에 `[종류, id]`를 열쇠로 넣습니다.

| 종류 | 내용 |
|---|---|
| children | 아이: 이름, 색, 순서 |
| subjects | 과목: 아이, 이름, 색, 순서 |
| tasks | 학습 내용: 과목, 이름, 계획 요일(0=일 … 6=토), 순서 |
| checks | 체크: 학습 내용, 날짜. id는 `학습내용id:YYYY-MM-DD`. 체크한 날만 저장하고 취소하면 지움 |

- 아이를 지우면 과목, 학습 내용, 체크가 함께 지워집니다. 과목을 지우면 학습 내용과 체크가, 학습 내용을 지우면 체크가 지워집니다.
- 화면 코드는 `src/data/`의 기능만 통해 저장합니다.

## 4. 개발 방식

- React + TypeScript + Vite 웹 앱. 학원노트와 같은 라이브러리 버전.
- 휴대폰 세로(아래쪽 탭 메뉴), 가로·PC(왼쪽 메뉴)에 대응. 항상 밝은 화면.
- 테스트: 계산 테스트(vitest), 화면 테스트(Playwright + PC의 Edge, 폰 세로 360×780 · 폰 가로 780×360 · PC 1366×768). 화면 테스트마다 내용이 화면보다 넓어지지 않았는지 검사합니다.
- 나중에 학원노트와 같이 Capacitor로 APK를 만들 수 있습니다.
